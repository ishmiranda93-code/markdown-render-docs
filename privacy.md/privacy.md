# Privacy Policy — Markdown Render for Confluence
Effective: November 17, 2026
Markdown Render for Confluence ("the App") renders Markdown entirely inside the user's browser within Confluence Cloud.
- Data collection: The App collects NO personal data and NO usage data. It operates no servers, no analytics, and no tracking.
- Data storage: The App stores nothing outside the Confluence page. Markdown source text is saved only as part of the page's macro configuration, controlled by Atlassian and the site's own permissions.
- Data transmission: The App makes no external network connections. Page content never leaves the user's Confluence site.
- Third parties: None. No subprocessors.
- Changes: Material changes to this policy will be published at this URL with a new effective date.
- Contact: via the Atlassian Marketplace listing for Markdown Render for Confluence (vendor: Seventh Visual).
